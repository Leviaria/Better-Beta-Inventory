# Better-Beta-Inventory

Brings modern inventory controls to Minecraft Beta 1.7.3. No more fumbling through menus to move items where you want them.

## Features

- **Number keys (1–9)** over any slot to send it directly to that hotbar slot — or pull from hotbar into an empty slot
- **Q** over any slot to drop one item from it
- **Shift + Q** over any slot to drop the entire stack
- **Right-click** armor pieces to instantly equip them into the correct armor slot
- **Shift + click** the crafting output to craft as many times as possible in one go
- Closing the **crafting grid** returns leftover ingredients to your inventory instead of scattering them on the floor
- All features work correctly in **multiplayer**

## Installation

### MultiMC / Prism Launcher
1. Right-click your Beta 1.7.3 instance and select **Edit Instance**
2. Go to the **Loader Mods** or **jar mods** tab
3. Click **Add to Minecraft.jar** and select the downloaded `.zip`
4. Launch the game

### Manual
1. Locate your `minecraft.jar` (`.minecraft/bin/minecraft.jar`)
2. Open it with any archive tool (e.g. 7-Zip or WinRAR)
3. Delete the **META-INF** folder inside the jar
4. Drag and drop the mod files into the jar
5. Save and launch the game
